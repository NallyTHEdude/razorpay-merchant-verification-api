# Merchant Analysis API
- An api to automate the verification and validity of a merchant, and to detect fradulant merchants without any human intervention
- This project uses swagger for endpoints documentation, so feel free to experiment using your own data.

---

# Tech Stack Used
1. Typescript + expressjs for building the rest API's.
2. zod for env and input validation.
3. Drizzle + PostgreSQL + PgVector for database connection and vector embeddings.
4. Swagger for OpenAPI documentation
